    iPad → Photo Frame

    Set up in ~2 minutes

    1
    Disable auto-lock. Go to Settings → Display & Brightness → Auto-Lock → set to Never.
    2
    Turn brightness up. Swipe up for Control Center and drag brightness to 100%.
    3
    Open Photo Frame app. Hit launch below, plug in charger, and prop it up. Done.
    ✕
    💊

    Phone → Med Reminder

    Set up in ~3 minutes

    1
    Charge the phone and place it somewhere visible — like a kitchen counter or bathroom shelf.
    2
    Open MediTrack Lite using the button below.
    3
    Add your medications with their times. Tap the circle each morning/evening to confirm you've taken them.
    4
    Optional: Bookmark this page to open it directly every day.
    ✕
    📞

    Tablet → Emergency Hub

    Set up in ~2 minutes

    1
    Place the tablet somewhere easily reachable — bedside table, kitchen, living room.
    2
    Open Emergency Hub below and add key contacts — family members, doctor, pharmacy.
    3
    Keep it charged. Plug in and leave this page open. One tap to call anyone.
    ✕
    🕐

    Any Device → Bedside Clock

    Set up in ~1 minute

    1
    Open Clock Dashboard using the button below and tap fullscreen mode.
    2
    Disable auto-lock in settings so the screen stays on. Plug in charger.
